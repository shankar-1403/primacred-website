# PRIMACRED

Premium corporate website for PRIMACRED — a strategic advisory and risk consulting firm focused on finance, risk, underwriting, insurance risk and business growth.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Motion
- Lucide React
- React Router DOM

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
